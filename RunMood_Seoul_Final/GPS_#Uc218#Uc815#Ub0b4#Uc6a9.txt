RunMood Seoul GPS 기능 추가본

추가 기능
1. 홈 화면에서 '내 GPS 위치를 사용해 가까운 코스를 우선 추천' 토글 제공
2. 브라우저 위치 권한을 통해 현재 위도/경도 및 GPS 정확도 표시
3. 사용자의 현재 위치와 각 러닝 코스 시작점 간 직선거리(Haversine) 계산
4. 기존 거리/기분/환경/보행/노면/고도/대기질 추천 점수는 유지하고, 가까운 코스에 GPS 근접 가산점 추가
5. 추천 결과에 '현재 위치에서 코스 시작점까지 약 X.XXkm' 표시
6. Leaflet 지도에 파란색 내 위치 마커와 코스 시작점까지 점선 표시
7. GPS 권한 거부/위치 조회 실패/모듈 미설치 시 오류 안내 추가

실행 전
pip install -r requirements.txt
streamlit run app.py

주의
- 브라우저 GPS는 위치 권한 허용이 필요합니다.
- 배포 환경에서는 HTTPS 사용을 권장합니다. localhost에서는 브라우저에 따라 위치 기능이 허용됩니다.
- GPS 거리는 도로 이동거리가 아니라 현재 위치와 코스 시작점 사이의 직선거리입니다.


[90코스 통합]
- data/courses.csv: 90코스 패치 기준 유지
- data/routes.geojson: 90개 경로 유지
- GPS OFF: 기존 v21.9 랜덤/감정/순환형/GPS아트 추천 유지
- GPS ON: 기존 종합점수 + GPS 근접 가산점으로 가까운 코스 우선
